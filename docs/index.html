A full music studio that runs on any computer.

Record, compose, mix and master on macOS, Windows and Linux. No account, no subscription, no internet. Made to run smoothly even on old and low-spec PCs.

Get Isai Source code

Isai (இசை) means music in Tamil.

Free forever

GPL-licensed and open source. No account, no login, no trial, no upsell. Your music stays on your computer.

Light on your PC

A native Rust audio engine and a GPU-light interface. Built for a dual-core CPU with 4 GB of RAM.

Easy, then deep

Start from a template and press play. When you need more, it's all there: automation, buses, mastering.

Arrange

Build your song, region by region.

Drag in any audio file and shape it on the timeline.

  • Edit freely: move, trim, split, fade, crossfade, loop and join
  • Follow tempo: loops stretch to your song's tempo without changing pitch
  • Markers for Intro, Verse and Chorus, and a cycle region that wraps any selection (⌘U)
  • Undo everything, with a history list to jump back several steps
Compose

A piano roll that helps you write.

Play from a MIDI keyboard or your computer keys, or draw notes in.

  • Chords in key: stamp chords that fit your song's key in one click
  • Strum and arpeggiate chords, and see your scale highlighted
  • Quantize with strength and swing, so it stays human
  • Ghost notes from other tracks to write parts that fit together
Instruments

Four instruments, ready to play.

Everything is built in and made from scratch, with nothing extra to download.

  • Isai Synth: two oscillators, sub, filter, envelopes, LFO and unison
  • Isai Piano: nine tones, from grand to electric, Wurli and Clav
  • Isai Drums: 808, 909, Acoustic, Lo-fi and Trap kits on a step grid
  • Isai Sampler: play any sound across the keys, or slice a loop on its beats
Beats

Program drums in seconds.

Click steps to add hits. Shift-click for an accent, Option-click for a soft hit, and drag to paint a whole row.

  • Five kits, synthesised so they stay tiny
  • Pattern presets to start from, plus swing
  • Tune, length, pan and level for each piece
Mix & master

Make it sound finished.

A mixer with buses and sends, 13 built-in effects, and an assistant that masters your song.

  • 8-band EQ with a live analyzer you can see your mix in
  • Effects: compressor, limiter, reverb, delay, chorus, flanger, phaser, distortion, bitcrusher, gate, de-esser and Pitch Correct
  • Mastering assistant: loud enough for Spotify and YouTube, without clipping
  • Export the song, a section or every track to WAV and FLAC
And more

The tools you reach for every day.

Record

Count-in, input monitoring and latency compensation, so takes land on the beat.

Tuner

A chromatic tuner for guitar and bass, built right in.

Automation

Draw volume, pan and any effect knob over time.

Browser

Find sounds, preview them in time with your song, and drag them in.

Track freeze

Render a heavy track to audio to free up your CPU.

Command palette

⌘K finds any command. Type "128 bpm", "bar 17" or "A minor".

Autosave

Crash recovery and self-contained project folders.

Any format

Import WAV, FLAC, MP3, OGG, AAC/M4A and AIFF.

Get it

Build it from source.

Ready-made downloads come with the first release. Until then, you can build it yourself in a few minutes.

  • • Rust 1.88 or newer
  • • Qt 6.9 or newer
  • • Linux: ALSA headers (libasound2-dev)
# macOS: install Qt
$ brew install qtbase qtdeclarative qtsvg qtshadertools

# get the code and run it
$ git clone https://github.com/DhineshKrishnan1206/isai-studio-pro
$ cd isai-studio-pro
$ cargo run --release

# Windows / Linux: install Qt 6.9+ with the Qt installer,
# then set QMAKE to its qmake before building.
