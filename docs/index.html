Start here02 / 06

your first song, in five steps.

The same guide that opens in the app. Each step lights up when you do it.

  1. Add a trackTracks are the lines of sound in your song. Click Add drum track to make one.
  2. Press playPlay starts the song from the beginning, so you can hear your track.
  3. Change the tempoTempo is how fast the song goes. Click the number and type a new one.
  4. Open the mixerThe mixer has one fader per track. Faders set how loud each track is.
  5. Add an effectPick a track in the mixer and add an Equalizer. Click the i button to learn what it does.

Why Isai04 / 06

Isai is not a trial, a subscription or a cut-down "lite" edition.

It brings together the tools that usually cost hundreds: a playlist, a piano roll, instruments, a mixer, effects and mastering, in one free app that you own.

It is built to run on the computer you already have. A dual-core laptop with 4 GB of RAM is the target, and every heavy feature can be turned down.

Start with a template and press play, then go as deep as you like. Isai (இசை) means music in Tamil.

Build it from source

get it from source.

Ready-made downloads come with the first release. Until then, building it takes a few minutes.

  • Rust 1.88 or newer
  • Qt 6.9 or newer
  • Linux only: ALSA headers (libasound2-dev)
~/music
# macOS: install Qt
$ brew install qtbase qtdeclarative qtsvg qtshadertools
 
# get the code and run it
$ git clone https://github.com/DhineshKrishnan1206/isai-studio-pro
$ cd isai-studio-pro
$ cargo run --release
 
# Windows / Linux: install Qt 6.9+ with the Qt installer,
# then set QMAKE to its qmake before building.
