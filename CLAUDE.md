# Isai Studio Pro

Free, open-source DAW (GPL-3.0). Rust engine + Qt 6 QML UI via cxx-qt 0.10.
Must run on low-spec PCs (dual-core, 4 GB RAM, integrated graphics) on macOS, Windows and Linux.

## Commands
- Run: `cargo run --release` (`-- song.wav` opens a new project with that file)
- Test: `cargo test --workspace` · Lint (CI-enforced): `cargo clippy --workspace --all-targets -- -D warnings`
- Screenshot a screen and quit: `ISAI_CONFIG_DIR=/tmp/isai-test ISAI_SCENE=<scene> ISAI_SCREENSHOT=/tmp/x.png cargo run`
  Scenes are listed in `crates/app/qml/Main.qml` (studio, mixer, piano, tempo, plugin[:name], stems, …).

## Layout (`crates/`)
- `engine` — audio thread, mixer, effects, instruments, `time.rs` (TempoMap). Never depends on the UI.
- `project` — song model (RON file + audio folder), edits, undo.
- `settings` — settings.toml, hardware profiles.
- `plugins` — CLAP (clack-host), VST3 (vst3-host), AU (macOS); scanning runs out-of-process (`isai --scan-plugins <file>`).
- `stems` — Spleeter 4-stem separation, native U-Net; model downloaded on first use.
- `app` — the `isai` binary: `src/*_ops.rs` (controller features), `qml/` (Theme/Icons/Auto/TimeMap singletons, components, pages).

## Docs to read only when needed
- `HANDOFF.md` — per-feature implementation notes and dev scenes (long; grep it, don't read it whole).
- `FEATURES.md` — feature checklist. Update both after each feature.
- `THIRD-PARTY-NOTICES.md` — every bundled font/library/model and its licence.

## Rules
- Audio thread: no allocation, no locks (plugins use `try_lock` and skip the block).
- Every heavy visual/audio feature needs a low-spec toggle; animations use `Theme.fast`/`Theme.slow`.
- Only add dependencies/assets with licences compatible with GPL-3.0; record them in THIRD-PARTY-NOTICES.md.
- No trademarks in sound/preset names. Artwork is generated by `tools/paint_art.py`, never copied.
- CI uses latest stable Rust: prefer `as_chunks` over `chunks_exact(N)`, avoid `fetch_update`.

## Gotchas
- QML property names `left`/`right`/`index`/`palette` clash with built-ins.
- `ShapePath` children can't use `parent`.
- Back up `crates/app/src/controller.rs` before big scripted edits; never read and write the same file in one expression.
